# Master
碩士畢業論文<br/>
開發PHP網頁雛形系統 (個人作品)<br/>
系統建置規格：<br/>
PHP、JavaScript、MySQL、CSS、HTML<br/>
<br/>
系統主要功能與流程：<br/>
1.使用者回饋流程：<br/>
(1)使用者註冊會員<br/>
(2)使用者登入<br/>
(3)使用者選擇回饋日期<br/>
(4)使用者對每篇文章，回饋與自己相關或不相關<br/>
(5)使用者每天總共回饋30篇文章<br/>
<br/>
2.系統處理流程：<br/>
(1)使用者每天回饋30篇文章後<br/>
(2)系統分析關鍵字<br/>
(3)系統分析關鍵字權重<br/>
(4)系統分析下一天尚未回饋文章，的排序權重<br/>
(5)系統下一天回饋文章顯示方式，依排序權重高到低優先顯示<br/>
<br/>
<br/>
由於系統需每日連續回饋三十篇，才有辦法進行關鍵字權重分析、排序權重分析<br/>
故不適合在網站上<br/>
供不特定人士進行不連續回饋<br/>
故本系統程式碼<br/>
僅在GitHub展示<br/>
