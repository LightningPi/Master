# Master
碩士畢業論文<br/>
開發PHP網頁雛形系統 (個人作品)<br/>
系統後台檔案位置：back資料夾<br/>
資料庫檔案：personalsearch.sql <br/>
<br/>
一、系統建置規格：<br/>
PHP、JavaScript、MySQL、CSS、HTML<br/>
<br/>
二、系統主要功能與流程：<br/>
1.使用者回饋流程：<br/>
(1)使用者註冊會員<br/>
(2)使用者登入<br/>
(3)使用者選擇回饋日期<br/>
(4)使用者對每篇文章，回饋與自己相關或不相關<br/>
(5)使用者每天總共回饋30篇文章(根據回饋結果，訓練系統獲得每天的關鍵字權重)<br/>
<br/>
2.系統處理流程：<br/>
(1)使用者每天完成回饋共30篇文章後<br/>
(2)系統分析過去3天，使用者完成回饋文章的所有關鍵字、關鍵詞，<br/>
(3)系統分析過去3天，關鍵字、關鍵詞，(3-A)在相關文章出現篇數、(3-B)在不相關文章出現篇數。(單一關鍵字在相關文章出現越多篇，對使用者的相關性權重越高)<br/>
(4)根據過去3天，已回饋文章的關鍵字權重，系統分析下一天每篇尚未回饋文章，的排序權重<br/>
(5)當使用者進行下一天回饋時，系統優先顯示排序權重較高的文章<br/>
<br/>
3.後台功能：<br/>
(1)新增會員搜尋結果<br/>
(2)搜尋結果列表<br/>
(3)儲存CKIP斷詞結果，讀取文字文件(.txt)內容，去除不需要資訊後，存進系統資料庫<br/>
<br/>
<br/>
三、系統限制：<br/>
當初進行論文實驗前<br/>
所有文章，已預先完成CKIP中文斷詞<br/>
並事先存進本系統資料庫<br/>
讓實驗能順利進行<br/>
