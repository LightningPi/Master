# Master
碩士畢業論文<br/>
開發PHP網頁雛形系統 (個人作品)<br/>
系統建置規格：<br/>
PHP、JavaScript、MySQL、CSS、HTML<br/>
<br/>
系統主要功能與流程：<br/>
1.使用者回饋流程：<br/>
(1)使用者註冊會員<br/>
(2)使用者登入<br/>
(3)使用者選擇回饋日期<br/>
(4)使用者對每篇文章，回饋與自己相關或不相關<br/>
(5)使用者每天總共回饋30篇文章<br/>
<br/>
2.系統處理流程：<br/>
(1)系統等待使用者，完成回饋每天第30篇文章後<br/>
(2)系統分析關鍵字<br/>
(3)系統分析關鍵字權重<br/>
(4)系統分析下一天尚未回饋文章，的排序權重<br/>
(5)當使用者進行下一天回饋時，系統優先顯示排序權重較高的文章<br/>
<br/>
3.後台功能：<br/>
(1)新增會員搜尋結果<br/>
(2)搜尋結果列表<br/>
(3)儲存CKIP斷詞結果，讀取文字文件(.txt)內容，存進資料庫<br/>
<br/>
後台系統檔案位置：back資料夾<br/>
<br/>
由於CKIP斷詞系統<br/>
無法線上動態執行<br/>
當初進行實驗時<br/>
CKIP斷詞已預先執行完成<br/>
故本系統程式碼<br/>
僅在GitHub展示<br/>
