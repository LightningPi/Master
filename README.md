# Master
碩士畢業論文<br/>
開發PHP網頁雛形系統 (個人作品)<br/>
系統後台檔案位置：back資料夾<br/>
資料庫檔案：personalsearch.sql <br/>
<br/>
系統建置規格：<br/>
PHP、JavaScript、MySQL、CSS、HTML<br/>
<br/>
系統主要功能與流程：<br/>
1.使用者回饋流程：<br/>
(1)使用者註冊會員<br/>
(2)使用者登入<br/>
(3)使用者選擇回饋日期<br/>
(4)使用者對每篇文章，回饋與自己相關或不相關<br/>
(5)使用者每天總共回饋30篇文章<br/>
<br/>
2.系統處理流程：<br/>
(1)系統等待使用者，完成回饋每天第30篇文章後<br/>
(2)系統分析關鍵字<br/>
(3)系統分析關鍵字權重<br/>
(4)系統分析下一天尚未回饋文章，的排序權重<br/>
(5)當使用者進行下一天回饋時，系統優先顯示排序權重較高的文章<br/>
<br/>
3.後台功能：<br/>
(1)新增會員搜尋結果<br/>
(2)搜尋結果列表<br/>
(3)儲存CKIP斷詞結果，讀取文字文件(.txt)內容，存進資料庫<br/>
<br/>
<br/>
附註：<br/>
由於中央研究院CKIP中文斷詞系統<br/>
文章斷詞流程<br/>
需將準備斷詞文章<br/>
另存成文字文件<br/>
並使用CKIP官方提供的，命令提示字元執行檔案<br/>
才可傳送文章到CKIP伺服器<br/>
進行中文斷詞<br/>
<br/>
故無法將實驗之後<br/>
由系統後台新增的文章<br/>
即時進行線上CKIP中文斷詞<br/>
當文章未進行CKIP中文斷詞分析<br/>
系統關鍵字處理流程就無法執行<br/>
故無法架設網站，線上實機展示本系統功能<br/>
<br/>
當初進行論文實驗前<br/>
所有文章，已預先完成CKIP中文斷詞<br/>
並存進本系統資料庫<br/>
讓實驗能順利進行<br/>
故本系統程式碼<br/>
僅在GitHub展示<br/>
